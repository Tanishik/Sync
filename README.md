Sync is a modern, responsive real-time messaging application built with **Flutter** and **Firebase**. Designed with a clean dark-mode aesthetic, floating navigation UI, and secure user authentication, Sync delivers a fast, low-latency chat experience across mobile devices.

 Key Features

* **Real-Time Messaging:** Instant data synchronization for direct messaging using Cloud Firestore.
* **Authentication Gate:** Secure email/password login and registration powered by Firebase Auth.
* **Modern Floating UI:** Custom floating bottom navigation bar with fluid screen transitions.
* **Clean Architecture:** Scalable directory structure separating models, UI components, pages, and backend services.
* **Responsive Dark Theme:** High-contrast dark mode tailored for readability and visual appeal.

 Tech Stack

* **Framework:** Flutter (Dart)
* **Backend:** Firebase (Authentication & Cloud Firestore)
* **UI & Styling:** Custom Flutter Widgets & Material Design

 Architecture & System Design

Sync follows a modular, layered architecture separating the presentation layer, domain services,and external integrations to ensure scalability and clean code separation.
